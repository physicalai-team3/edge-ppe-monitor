# 05. PPE 모델 비교: YOLOv8n vs YOLOv8s

2026-11-02 · 팀원 3 (Pi)

**결론: YOLOv8n을 계속 쓴다. YOLOv8s는 채택하지 않는다.** s는 테스트 사진 25장 중 16장을 맞혀 n(19장)보다 낮았고, 위반을 더 많이 놓쳤으며(10/16 vs 13/16), 노트북에서 2.8배 느렸다(160ms vs 57ms).

- Pi 5에서 n 추론은 약 174ms로, gateway의 4초 제한 안에 여유가 크다.
- 검증 mAP50(우리가 쓰는 5개 클래스 평균)은 n 0.681, s 0.687로 사실상 같다.
- 두 모델 모두 보호구를 자주 놓친다. 한계는 모델 크기보다 학습 데이터(공사장 사진 약 2,800장)에 있다.

## 학습 조건

두 모델은 같은 데이터로 Google Colab(무료 T4 GPU)에서 학습했고, 모델 크기와 epoch만 다르다. 학습 방법은 [pi/detector/models/README.md](../pi/detector/models/README.md).

| 항목 | YOLOv8n | YOLOv8s |
|---|---|---|
| 파라미터 수 | 약 310만 | 약 1,110만 |
| 데이터셋 | Roboflow Construction Site Safety v30 (25 클래스) | 같음 |
| 입력 크기 | 640 | 640 |
| epoch | 50 (끝까지) | 최대 80, patience 20 → 22에서 최고, 42에서 조기 종료 |
| ONNX 파일 크기 | 13MB | 45MB |

s가 22 epoch에서 멈춘 것은 큰 모델이 약 2,800장을 빨리 다 배우고 그 뒤로 검증 성적이 오르지 않았다는 뜻이다. 우리가 쓰는 클래스는 Person, Hardhat, NO-Hardhat, Safety Vest, NO-Safety Vest 5개다.

## 검증 지표 (검증 사진 114장, mAP50)

| 클래스 | YOLOv8n | YOLOv8s | 변화 |
|---|---|---|---|
| Person | 0.777 | 0.780 | 비슷 |
| Hardhat | 0.714 | 0.775 | ▲ |
| NO-Hardhat | 0.583 | 0.598 | 약간 ▲ |
| Safety Vest | 0.741 | 0.646 | ▼ 크게 떨어짐 |
| NO-Safety Vest | 0.592 | 0.637 | ▲ |
| **5개 평균** | **0.681** | **0.687** | 거의 같음 |

s는 찾은 박스가 더 정확하지만(정밀도 P: n 0.710 → s 0.825) 더 많이 놓친다(재현율 R: n 0.494 → s 0.453, 25개 클래스 전체). 우리 시스템의 문제는 보호구를 놓치는 것이라, 재현율이 낮아진 것이 더 크게 작용한다.

## 테스트 사진 25장 판정 결과

n이 25장 중 19장, s가 16장을 맞혔다. 사진은 위키미디어 공용에서 고른 착용 9장과 위반 16장이고, 판정 규칙은 둘 다 D안([03 §5.2](03-contracts.md#52-사람별-착용-여부): 점수 높은 쪽, 안 보이면 통과)이다.

| 지표 | YOLOv8n | YOLOv8s |
|---|---|---|
| 전체 판정 정확 | **19/25** | 16/25 |
| 착용자를 정상으로 (오경보 없음) | 6/9 | 6/9 |
| 위반자를 위반으로 (놓치지 않음) | **13/16** | 10/16 |
| 위반 종류까지 정확 | **7/16** | 5/16 |

두 모델의 판정이 다르거나 틀린 사진만 모았다.

| 사진 | 장면 | 정답 | n | s |
|---|---|---|---|---|
| a01 | 공사장 3명, 모두 착용 | 정상 | ✗ no_vest | ✓ 정상 |
| a03 | 안전모·조끼 착용 근접 | 정상 | ✓ 정상 | ✗ no_vest |
| a06 | 주황 멜빵형 작업복 | 정상 | ✗ no_vest | ✗ no_vest |
| b13 | 형광 재킷 + 안전대 | 정상 | ✗ no_vest | ✓ 정상 |
| b14 | 형광 작업복 2명 | 정상 | ✓ 정상 | ✗ no_vest |
| a04 | 안전모만, 상의 탈의 | no_vest | ✓ no_helmet | ✗ 정상 |
| a10 | 일반 야구모자 | no_helmet, no_vest | ✗ 정상 | ✓ no_helmet |
| b05 | 조끼만, 안전모 없음 | no_helmet | ✓ no_helmet | ✗ 정상 |
| b07 | 안전모만, 빨간 티셔츠 | no_vest | ✓ no_vest | ✗ 정상 |
| b08 | 안전모 얼굴 클로즈업 | no_vest | ✗ 정상 | ✗ 정상 |
| b10 | 안전모만, 실내 | no_vest | ✗ 정상 | ✗ 정상 |
| b11 | 안전모만, 작업실 | no_vest | ✓ no_vest | ✗ 정상 |

✓/✗는 위반 여부가 맞았는지를 뜻한다(a04의 n은 위반은 맞추었지만 종류는 틀렸다). s는 보호구를 하나만 빠뜨린 사람(b05, b07, b11, a04)을 대부분 정상으로 판정했다. s가 나아진 곳은 일반 모자(a10)를 위반으로 잡은 것뿐이다.

## CONF_THRESHOLD 실험

테스트 사진 25장 중 판정이 맞은 수.

| CONF_THRESHOLD | 0.2 | 0.25 | 0.3 | **0.4 (현재)** |
|---|---|---|---|---|
| YOLOv8n | 18 | 18 | 19 | **19** |
| YOLOv8s | 18 | 17 | 16 | 16 |

기준을 낮추면 놓치던 위반을 더 잡지만 그만큼 오경보도 늘어, n은 0.4에서 바꿀 이유가 없다. s는 0.2까지 낮춰도 n 0.4에 미치지 못한다.

## 추론 속도

Pi 5에서 n은 사진 1장에 약 174ms로, gateway가 detector를 기다리는 4초 제한의 약 4%다.

| 환경 | YOLOv8n | YOLOv8s |
|---|---|---|
| 노트북 CPU (테스트 사진 25장 평균) | 57ms | 160ms |
| Raspberry Pi 5 (bus.jpg, gateway 경유) | 약 174ms | 미측정 (약 450~500ms 예상) |

Pi 측정값은 5번 전송한 것 중 첫 번째(156ms, 준비 과정 포함)를 뺀 152, 162, 159, 221ms의 평균이다. s의 Pi 값은 노트북에서의 배율(2.8배)로 어림잡은 것이다.

## 다음 단계

모델을 키워도 나아지지 않았으므로, 다음 개선은 학습 데이터를 늘리는 쪽이다.

- [ ] 시연 장소(교실)에서 안전모·조끼를 쓰고 벗으며 사진 50~100장 촬영 → Roboflow 라벨링 → n 재학습
- [ ] 재학습 모델을 같은 테스트 사진 25장 + 교실 사진으로 다시 비교
- [ ] 판정 규칙 D안(03-contracts §5.2 변경) 팀 합의

테스트 사진이 25장뿐이고 야외 공사장 위주라, 숫자는 참고값이다. 실제 ESP32 카메라(VGA, 실내, 1~3m) 사진에서의 성능은 따로 확인해야 한다.
